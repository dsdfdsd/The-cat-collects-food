RUS:
Простенькая 2d, в которой вам нужно будет собирать монетки и уклонятся от лис. Для компиляции, в моем случае пайчарм, 
установить пайгейм и pyinstaller и затем прописать в терминал pyinstaller --onefile main.py, затем
взять exe файл, создать отдельную папку, кинуть туда exe и папки (cat_left,cat_right,cat_sit,cat_sleep_right,fonts,fox,images).
Управление можно посмотреть в игре нажав на кнопочку Controls (откроется браузер и там управление)

ENG:
A simple 2D game in which you will need to collect coins and dodge foxes. To compile, in my case, paycharm,
install pygame and pyinstaller and then register pyinstaller --onefile in the terminal. main.py then
take the exe file, create a separate folder, and throw in the exe and folders (cat_left,cat_right,cat_sit,cat_sleep_right,fonts,fox,images).
You can view the controls in the game by clicking on the Controls button (the browser opens and controls there)
